# hashcott.github.io

Trang cá nhân tại <https://hashcott.github.io>, build bằng Jekyll của GitHub Pages (không dùng theme).

- **Dự án:** sửa `_data/projects.yml`.
- **Thông báo cập nhật:** thêm file `_posts/YYYY-MM-DD-ten-bai.md` có `type: update` trong front matter.
- **Bài viết:** như trên nhưng bỏ `type: update`.

Chạy thử ở máy: `bundle install && bundle exec jekyll serve`.
